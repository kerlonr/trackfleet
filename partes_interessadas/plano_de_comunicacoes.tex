\section{Classificação da Informação}
\begin{itemize}[itemsep=2pt]
  \item \textbf{Sensível:} posições, trajetos e dados dos motoristas ficam só dentro da plataforma, com acesso autenticado; nunca vão para relatórios de status, atas ou e-mails.
  \item \textbf{Interna:} indicadores do projeto, riscos e decisões circulam entre GPs e patrocinador.
  \item \textbf{Externa:} o que vai para o provedor da API se limita a dados técnicos da integração; o que vai para os motoristas é o aviso de privacidade.
\end{itemize}

\section{Monitorar as Comunicações}
\begin{itemize}[itemsep=4pt]
  \item \textbf{Feedback do patrocinador:} a cada relatório executivo, uma pergunta só --- ``este relatório ajudou você a decidir?''. Duas respostas negativas seguidas mudam o formato (mais curto, menos termos técnicos).
  \item \textbf{Feedback do gestor de frota:} a ata de cada demonstração registra o que foi entendido e o que ficou confuso; itens confusos voltam na demonstração seguinte.
  \item \textbf{Ajuste de rota:} se a sincronização diária deixar de pegar bloqueios a tempo (por exemplo, um bloqueio descoberto só no check-in semanal), a frequência ou a ferramenta é revista no check-in seguinte.
  \item \textbf{Revisão do plano:} o plano é revisto a cada marco do Cronograma, junto com o Registro das Partes Interessadas.
\end{itemize}
